# Loan Approval Prediction System

## About the Project

Loan Approval Prediction System is a machine learning web application designed to predict whether a loan application is likely to be approved based on applicant information.

The system uses a machine learning model together with a Flask web application to process loan applications and display prediction results.

## Technologies Used

* Python
* Flask
* Pandas
* Scikit-learn
* HTML
* CSS
* JavaScript
* Node.js
* MongoDB

## Main Features

* Loan approval prediction
* Machine learning model integration
* Web-based loan application form
* User registration and login
* Loan prediction results
* Applicant information processing
* Flask API
* USSD loan application component

## Machine Learning

The system uses a trained machine learning model to make loan approval predictions based on applicant information.

The project includes trained model files such as:

* `loan_approval_model.pkl`
* `loan_approval_pipeline.pkl`
* `loan_scaler_model.pkl`

## How to Run

1. Install Python.
2. Install the required Python packages.
3. Make sure the required services such as MongoDB are running if the application uses them.
4. Open the project folder in VS Code.
5. Run the Flask application.
6. Open the application in a web browser.
